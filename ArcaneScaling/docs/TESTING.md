## 证据格式

可复现且脱敏的文本证据可放 docs/evidence/。大型截图/日志另存时记录稳定位置及校验值；不提交个人存档。
状态仅用：未执行、通过、失败、阻塞。无记录不可推定通过。

## 最小实验顺序
1. 独立测试配置建立未安装本 Mod 的对照，记录法术、目标、抗性、perk、难度。
2. 安装内容与 DLL，在无自定义附魔时对照原行为。
3. 装备单件已知强度物品，对同一场景重复测试。
4. 分别改变抗性、perk、双手施法；一次只改一个变量。
5. 卸下装备、换施法者、重复施放与读档，检查状态泄漏。
6. 增加效果类型及第三方组合时新增测试记录，再扩大支持范围。

伤害观测只是证据之一；需结合实例输入/输出及回调次数，不能仅凭目标少血量推断 Hook 顺序正确。
